# Urdu store listing (translation) — copy and paste into Play Console

This is the Urdu translation of `listing.md`. Same facts, nothing added. The app
itself stays in English; the listing says so, so an Urdu reader is not misled.

Play shows this translation to people whose phone language is Urdu. Everyone
else keeps seeing the English listing. Lengths were checked with a script on
29 Sep 2026 (see `ASO.md`, "Length check").

## How to add it in Play Console

1. Play Console → your app → **Grow users → Store presence → Main store listing**.
2. Top right: **Manage translations → Add your own translations**
   (some Console versions call this step **Select languages**).
3. Tick **Urdu – ur** → **Apply** (or **Apply and save**).
4. At the top of the listing, switch the language selector from
   *English (United States) – en-US* to **Urdu – ur**.
5. Paste the three blocks below into App name, Short description and Full
   description. Leave the graphics empty: Play then uses the English
   screenshots and feature graphic, which is what we want (the app is in English).
6. **Save** → send the change for review with the next release or on its own.

Do **not** turn on machine translation for Urdu; this text replaces it.

## Notes

- Mixed Urdu and Latin text (the brand, the Roman Urdu example) displays
  correctly on Android; the title starts with "Inkpot", so it reads left to right
  up to the colon and the Urdu words read right to left after it.
- "بیچ" is used only in the sense of *batch* (the word teachers use), with
  "(batch)" the first time; "middle of the month" is written "مہینے کے درمیان"
  so the two meanings never clash.
- Before publishing, ask one Urdu-reading teacher to read the short description
  aloud. If any word sounds bookish to them, swap it for the word they use; keep
  the length at 80 or less.
